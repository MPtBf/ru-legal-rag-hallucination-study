# Финальная разметка ответов (v2)

Папка содержит итоговую разметку шести прогонов на промпте v2: zero-shot и RAG (naive, hybrid) для GigaChat и DeepSeek.

- `annotations_v2.xlsx` — 1266 строк (6 × 211): ответы моделей, метка галлюцинации, тег, комментарий, найденные статьи и признаки `Эталонная статья в контексте`, `Отказ`.
- `_итоги.tsv` — агрегаты по прогонам.
- `results_fig1.png` — рисунок 1 для раздела «Результаты».

**Ключевые числа:** 341 галлюцинация из 1266 (26,9 %); отказов 29, из них 11 при эталонной статье в контексте и 18 без неё. Теги: `ВЫДУМАННЫЙ ФАКТ` 135, `НЕВЕРНАЯ СТАТЬЯ` 123, `УПУЩЕНИЕ` 80, `ВЫДУМАННАЯ СТАТЬЯ` 3.

Происхождение, правила, хеши и ограничения — в [`docs/data/annotation-provenance.md`](../../docs/data/annotation-provenance.md).

## Проверка

```powershell
python scripts/verify_annotations.py
python scripts/compute_annotation_stats.py
python scripts/make_results_fig.py
```

`verify_annotations.py` сверяет ответы и retrieval с `results/**/*_v2.xlsx`, проверяет правило отказов и соответствие «метка ⟺ тег». Ожидается 1266 строк, 341 галлюцинация, 29 отказов. Для hybrid DeepSeek ID 112 скрипт выводит предупреждение: в `results` не заполнена колонка найденных статей, в размеченном источнике retrieval есть.

## Важно

`annotations_v2.xlsx` — источник истины для чисел статьи. При любом изменении таблицы обновите `_итоги.tsv`, рисунок, хеши в карточке `docs/data/annotation-provenance.md`, числа в этом README и в разделах Methods/Results. Перед фиксацией запустите проверки выше.
