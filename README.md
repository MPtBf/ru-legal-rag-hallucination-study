# Снижение галлюцинаций в русскоязычных юридических RAG-системах: систематическое сравнение гибридного, графового и агентного поиска

Эксперименты по сравнению RAG-стратегий (naive → hybrid → graph) на русскоязычном трудовом праве РФ. В текущей версии реализован режим `zero_shot` с возможностью автоматической оценки ответов LLM-судьей. RAG-режимы добавляются позже.

## Установка

Для **VS Code** (из терминала PowerShell):
```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

Для **PyCharm** (терминал с уже активированным окружением `.venv`):
```bash
pip install -r requirements.txt
```

Ключи API (`GIGACHAT_AUTH_KEY`, `DEEPSEEK_API_KEY`) хранятся в файле `.env` (шаблон — `.env.example`). При запуске скрипты автоматически подтягивают их оттуда, вам не нужно передавать их вручную.

## Запуск

Единый раннер `run.py` поддерживает базовые модели из `config.py` и кастомные параметры.

### VS Code
```bash
# Базовый запуск (без оценки)
venv\Scripts\python run.py --mode zero_shot --model GigaChat-2-Pro

# Запуск с автоматической оценкой галлюцинаций (LLM-судья)
venv\Scripts\python run.py --mode zero_shot --model GigaChat-2-Pro --limit 5 --evaluate
```

### PyCharm
```bash
# Базовый запуск (без оценки)
python run.py --mode zero_shot --model GigaChat-2-Pro

# Запуск с автоматической оценкой галлюцинаций
python run.py --mode zero_shot --model GigaChat-2-Pro --limit 5 --evaluate
```

### Параметры запуска
* `--mode` — режим эксперимента (сейчас реализован `zero_shot`).
* `--model` — модель для генерации ответов. Можно использовать алиасы `gigachat`/`deepseek` (возьмут значения по умолчанию из `config.py`) или указывать точные имена: `GigaChat-Pro`, `GigaChat-2-Pro`, `deepseek-chat`, `deepseek-reasoner` и др.
* `--limit N` — обработать только первые N вопросов (для быстрой проверки).
* `--output-path PATH` — сохранить результат по указанному пути вместо `results/`.
* `--evaluate` — флаг для включения автоматической оценки. Если указан, судья проверит ответы и заполнит колонки «Была галлюцинация» и «Комментарий». Пишется просто как флаг.
* `--evaluate_model` — модель для проведения оценки (по умолчанию `deepseek-reasoner`).

При продолжении запуска ответы сопоставляются по тексту вопроса (нумерация `№` может расходиться), а ответы вида `[Ошибка ...]` считаются незаполненными и запрашиваются повторно.

Если для этого режима, модели и версии промпта уже есть таблица результатов, запуск продолжается с последней записи: готовые ответы не перегенерируются. Для нового дня создаётся новый файл.

Тестовый прогон на 5 вопросах:

**VS Code:**
```bash
venv\Scripts\python run.py --mode zero_shot --model GigaChat-2-Pro --limit 5 --evaluate
```
**PyCharm:**
```bash
python run.py --mode zero_shot --model GigaChat-2-Pro --limit 5 --evaluate
```

## Структура проекта

* `config.py` — пути к данным, API-ключи, константы моделей и списки `allowed_giga_models` / `allowed_deepseek_models`.
* `prompts.py` — тексты промптов (системный, для генерации и для оценщика) и версия промпта (`PROMPT_VERSION`).
* `run.py` — единый раннер всех экспериментов (управляет циклом, сохранением, оценкой).
* `evaluate.py` — логика LLM-судьи. Парсит JSON-ответ от нейросети-оценщика и формирует вердикт о наличии галлюцинации.
* `llms.py` — LangChain-обертки для `GigaChat` и `DeepSeek` с валидацией выбранной модели.
* `experiments/` — пайплайны режимов (`zero_shot/`). Новый режим регистрируется декоратором `@register_pipeline("имя")`.
* `data/dataset.xlsx` — датасет из 211 юридических кейсов с эталонными ответами и ссылками на статьи ТК РФ.
* `data/corpus/tk_rf_articles.jsonl` — корпус статей ТК РФ (534 статьи) для будущего RAG.
* `data/index/` — каталог для индекса RAG (создаётся при построении индекса, содержимое не хранится в git).

## Результаты

Результаты сохраняются в `results/{mode}/{model}/`.
Имя файла: `{mode}_{model}_{дата}_v{версия_промпта}.xlsx`. Если была включена оценка, добавляется суффикс `_eva_{evaluate_model}.xlsx`.
Рядом создается `..._metadata.json` с параметрами прогона, текстами промптов и информацией об оценщике.

* `results/zero_shot/GigaChat-2-Pro/` — Zero-shot, ответы GigaChat (без базы знаний).
* `results/zero_shot/deepseek-reasoner/` — Zero-shot, ответы DeepSeek (без базы знаний).

Если при запуске был указан флаг `--evaluate`, в итоговом Excel-файле автоматически заполняются две крайние колонки:
1. **Была галлюцинация (да/нет)** — вердикт модели-судьи.
2. **Комментарий** — краткое обоснование от судьи с цитатой ошибки (если она была).
