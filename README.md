# Снижение галлюцинаций в русскоязычных юридических RAG-системах: систематическое сравнение гибридного, графового и агентного поиска

Эксперименты по сравнению RAG-стратегий (naive → hybrid → graph) на русскоязычном трудовом праве РФ. Сейчас реализован только `zero_shot`, RAG-режимы добавляются позже.

## Установка

```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

Ключи API — в `.env` (шаблон — `.env.example`).

## Запуск

```bash
venv\Scripts\python run.py --mode zero_shot --model gigachat
venv\Scripts\python run.py --mode zero_shot --model deepseek
```

* `--limit N` — обработать только первые N вопросов (для проверки)
* `--output-path PATH` — свой путь к результату (внутри `data/` запрещён)
* `--force` — очистить ответы и перегенерировать всё заново

Повторный запуск продолжает таблицу: готовые ответы пропускаются (в том числе на следующий день), незаполненные запрашиваются заново. Быстрый тест:

```bash
venv\Scripts\python run.py --mode zero_shot --model gigachat --limit 5 --output-path results\_test\test.xlsx
```

### Условия и `--force`

Рядом с таблицей лежит `*_metadata.json` с условиями прогона (модель, промпт, температура, колонка ответов) и провенансом. Перед запуском они сверяются с текущими настройками: при расхождении скрипт печатает различия и выходит с кодом 2, не тратя токены. Если метаданных нет — тоже код 2.

`--force` снимает проверку и генерирует ответы с нуля: очищает колонку ответов и разметку, остальные колонки не трогает. Бэкапа нет, поэтому применяйте осознанно. Изменения датасета и git-коммита запуск не блокируют — о них скрипт только предупреждает.

## Ошибки и повторы

До 5 попыток на запрос: паузы 2, 4, 8, 16 с (или `Retry-After` от сервера), таймаут запроса 30 с. Повторяются только временные сбои (сеть, таймауты, 408, 429, 5xx), остальные завершают прогон сразу. Логи — в `logs/{mode}_{model}_{дата}.log`. Если попытки исчерпаны, скрипт выходит с кодом 1; полученные ответы уже сохранены и при перезапуске будут пропущены.

## Структура

* `config.py` — пути, ключи, константы моделей
* `prompts.py` — промпты и `PROMPT_VERSION`
* `run.py` — единый раннер экспериментов
* `experiments/zero_shot/` — `llms.py` и `pipeline.py`; новый режим регистрируется через `@register_pipeline("имя")`
* `data/dataset.xlsx` — 211 кейсов с эталонными ответами и статьями ТК РФ
* `data/corpus/tk_rf_articles.jsonl` — корпус статей ТК РФ (534 статьи)
* `data/index/` — индекс RAG (не хранится в git)

## Результаты

`results/{mode}/{model}/{mode}_{model}_{версия_промпта}.xlsx`, рядом — метаданные прогона.
