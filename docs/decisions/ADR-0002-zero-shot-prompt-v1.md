# ADR-0002: Откат zero-shot промпта до v1

**Дата:** 07.11.2026
**Статус:** принято (решение участника проекта).

## Контекст

В `prompts.py` использовались две независимые версии промптов:

- `PROMPT_VERSION` — системный промпт zero-shot (`SYSTEM_PROMPT`);
- `RAG_PROMPT_VERSION` — системный промпт RAG-режимов (`RAG_SYSTEM_PROMPT`), который строится как `SYSTEM_PROMPT` + RAG-надстройка.

Коммит `7fe6816` перевёл zero-shot на v2: к трём исходным предложениям был добавлен блок «ПРАВИЛА ОТВЕТА» из пяти пунктов. RAG-надстройка при этом начиналась с пункта `6.` и продолжала нумерацию этого блока. Коммит `3086e4a` перенёс RAG-промпт в корневой `prompts.py` и ввёл отдельную константу `RAG_PROMPT_VERSION`.

Сохранённые результаты `results/**/*_v2.xlsx` и metadata получены с промптами v2. Перегенерация ответов не планируется.

## Решение

1. `PROMPT_VERSION` возвращается к `v1`; `SYSTEM_PROMPT` восстанавливается в виде трёх исходных предложений без блока «ПРАВИЛА ОТВЕТА» (текст коммита `69afaa8`).
2. `RAG_PROMPT_VERSION` остаётся `v2`. Текст `RAG_SYSTEM_PROMPT` сохраняется, но из RAG-надстройки удаляется только номер `6.`, поскольку нумерованный список, который он продолжал, больше не входит в `SYSTEM_PROMPT`.
3. `EVALUATE_PROMPT` не меняется: у него нет версии v1, он появился вместе с v2.
4. Сохранённые результаты и metadata не изменяются и не перегенерируются.

## Обоснование

- Откат нужен для zero-shot; RAG-режимы по условиям задачи остаются на текущем промпте.
- Удаление номера `6.` — косметическая правка, устраняющая ссылку на отсутствующий список. Содержание RAG-инструкций не меняется, поэтому версия RAG не повышается.
- Существующие v2-результаты остаются каноническими для уже проведённых прогонов; новые прогоны под v1 в этот ADR не входят.

## Последствия и ограничения

- Код в рабочем дереве и сохранённые v2-результаты теперь описывают разные условия генерации. Это осознанное решение: результаты не перегенерируются, а расхождение фиксируется здесь.
- `run.py` формирует имя файла как `results/{mode}/{model}/{mode}_{model}_{prompt_version}.xlsx`. Для zero-shot это теперь `*_v1.xlsx`.
  - Для GigaChat файл `results/zero_shot/gigachat/zero_shot_gigachat_v1.xlsx` уже существует; metadata v1 рядом отсутствует. При попытке продолжить запись `run.py` остановится на проверке metadata/условий, пока не будет выбран новый `--output-path` или `--force`.
  - Для DeepSeek файл Zero-Shot v1 был удалён коммитом `7fe6816` и в рабочем дереве отсутствует (см. ADR-0001).
- Точный текст `RAG_SYSTEM_PROMPT` формально отличается от текста, сохранённого в metadata прежних v2-прогонов, хотя версия остаётся `v2`. Повторная запись в существующие RAG v2-файлы также будет остановлена проверкой условий `run.py`.
- Если в дальнейшем потребуется повышать версию при любом изменении текста, включая косметическое, `RAG_PROMPT_VERSION` следует пересмотреть отдельным решением.
