# ADR-0004: Возврат промпта к v2 после прогонов v3

**Дата:** 08.11.2026
**Статус:** принято (решение участника проекта).

## Контекст

По [ADR-0003](ADR-0003-rag-v3-regeneration.md) были выполнены четыре RAG-прогона на промпте `v3`, а их результаты сохранены и закоммичены. После этого участник проекта попросил вернуть код к версии, на которой были созданы результаты v2 (в частности, `results/hybrid_rag/gigachat/hybrid_rag_gigachat_v2.xlsx`), не удаляя результаты прогонов v3.

Результаты v2 создавались на коммите `b462385`; для трёх из четырёх прогонов metadata фиксирует `git_dirty=true`, поэтому точное состояние всего рабочего дерева на момент запуска по git восстановить нельзя. Однако полный текст промпта сохранён в metadata, и для всех четырёх RAG v2-файлов он совпадает.

## Решение

1. `prompts.py` восстанавливается из коммита `b462385`:
   - `PROMPT_VERSION = "v2"`;
   - `RAG_PROMPT_VERSION = "v2"`;
   - `SYSTEM_PROMPT` содержит блок «ПРАВИЛА ОТВЕТА» из пяти пунктов;
   - RAG-надстройка снова содержит пункт `6.`.
2. Результаты v3 (`*_v3.xlsx`, `*_v3_metadata.json`, `*_v3_retrieval.jsonl`) остаются без изменений.
3. Повторная генерация не выполняется; старые v2-результаты также не изменяются.
4. Решение ADR-0002 об откате zero-shot до `v1` и решение ADR-0003 о версии `v3` отменяются в части текущего состояния кода; сами ADR сохраняются как история.

## Обоснование

- Восстановленный `RAG_SYSTEM_PROMPT` (870 символов) побайтово совпадает с `system_prompt` во всех четырёх RAG v2-metadata, включая указанный `hybrid_rag_gigachat_v2.xlsx`.
- Это возвращает коду способность воспроизводить условия v2 без ручной правки промпта.
- Сохранение v3-файлов не даёт потерять уже выполненную работу и оставляет provenance этих прогонов.

## Последствия и ограничения

- Текущий код снова генерирует промпт v2; по умолчанию RAG-запуски будут нацелены на существующие `*_v2.xlsx`, а zero-shot — на `*_v2.xlsx`.
- Существующие v2-файлы заполнены полностью; повторный запуск без `--force` должен пропустить готовые ответы, а с `--force` перезапишет их.
- Результаты v3 нельзя воспроизвести текущим кодом без возврата промпта v3; их metadata по-прежнему фиксирует версию `v3` и точный текст того промпта.
- Zero-shot v2-metadata содержит историческое отличие: между пунктами 4 и 5 нет перевода строки, поэтому его `system_prompt` (509 символов) не совпадает побайтово с текущим `SYSTEM_PROMPT` (510 символов). Для указанного RAG v2-файла совпадение точное; точное воспроизведение zero-shot v2 требует отдельного решения.
