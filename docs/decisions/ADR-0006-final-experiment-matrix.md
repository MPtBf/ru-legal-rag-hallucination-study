# ADR-0006: Итоговая матрица экспериментов и промпт v2

**Дата:** 12.11.2026
**Статус:** принято (подтверждено Марком; тимлид утвердил матрицу).

## Контекст

Первоначальный бриф тимлида описывал сравнение Zero-Shot и Naive RAG. В ходе работы был реализован Hybrid RAG, а версии промптов менялись: RAG v3 (07–08.11.2026) был собран на базе промпта v1 с RAG-надстройкой, после чего проект вернулся к v2. Zero-shot прогоны были перегенерированы на v2 08.11.2026. Возникла неоднозначность, какие файлы считать итоговыми и можно ли смешивать v2 и v3.

## Решение

1. В статью входят шесть экспериментов: `zero_shot`, `naive_rag`, `hybrid_rag` для GigaChat и DeepSeek.
2. Итоговые прогоны — на промпте v2:
   - zero-shot v2 — 08.11.2026, обе модели, по 211 ответов;
   - naive RAG v2 — 31.10.2026, обе модели;
   - hybrid RAG v2 — 31.10.2026, обе модели.
3. RAG v3 (07–08.11.2026) считается архивным. Его нельзя смешивать с v2: в v3 другая база системного промпта, поэтому сравнение с zero-shot v2 было бы смещено.
4. Общая база — `SYSTEM_PROMPT` v2; RAG использует `RAG_SYSTEM_PROMPT` v2 (та же база + правило 6).
5. Параметры генерации: temperature 0.1; запрошенные модели `GigaChat-2` и `deepseek-chat`; фактические `response_model` — `GigaChat-2:2.0.30.01` и `deepseek-flash`.
6. Датасет: 211 вопросов на основе ТК РФ, 11 вопросов с ложной предпосылкой (ID 201–211), эталонные ответы со ссылкой на статью. Корпус: 534 статьи ТК РФ (RuLawRetrieval, редакция 25.05.2026).
7. Оценка: четыре тега, `УПУЩЕНИЕ` входит в галлюцинации; на каждый ответ ставится одна метка по приоритету (`ВЫДУМАННАЯ СТАТЬЯ` → `ВЫДУМАННЫЙ ФАКТ` → `НЕВЕРНАЯ СТАТЬЯ` → `УПУЩЕНИЕ`). Разметка двухэтапная: предварительная автоматическая метка LLM-судьи, затем проверка и исправление человеком; итоговой считается проверенная человеком метка. Каждый прогон размечал один участник; согласие не измерялось, юрист не привлекался.
8. Оформление статьи: DOCX; 12–13 пт; интервал 1,5; Times New Roman; отступ первой строки 1,25; сноски 10 пт; выравнивание по ширине; поля 3/2/2/2 см. Возможны уточнения после выбора журнала.

## Обоснование

- Единая версия промпта v2 делает сравнение Zero-Shot и RAG сопоставимым по базовой инструкции.
- v3 результаты полезны как история и проверка, но их нельзя подписывать как «тот же промпт», что и zero-shot v2.
- Шесть прогонов покрывают три архитектуры и две модели при одинаковых данных и параметрах генерации.

## Последствия и ограничения

- Если команда решит использовать v3, потребуется либо перегенерировать zero-shot на базе v3, либо явно описать различие промптов как ограничение. Текущее решение — v2.
- В metadata части RAG v2-прогонов есть `git_dirty=true`; ответы и provenance сохранены, но утверждать «чистый прогон в одном коммите» без отдельной проверки нельзя.
- Точный протокол человеческой разметки новых zero-shot v2 и RAG-файлов ещё не зафиксирован в репозитории.
- Проверенные метки шести прогонов лежат только в `.tmp/проверенные-ответы/` и не закоммичены; в `results/*.xlsx` остаются автоматические метки. Числа расходятся: zero-shot GigaChat 116 «да» против 94 в `results/`, zero-shot DeepSeek 69 против 25, hybrid GigaChat 60 против 49. Для Results нужно использовать проверенные файлы и зафиксировать их в репозитории.
- 13.11.2026 проверенные таблицы приведены к единому формату (`.tmp/форматированные-проверенные-ответы/`, 6 файлов + `все-прогоны.xlsx` + `_сводка.md`): одна метка «да/нет», один тег, комментарий разметчика, тег и метка согласованы во всех 1266 строках. Правило — «есть тег — галлюцинация, нет тега — чисто»; итог 116 / 69 / 53 / 32 / 60 / 21 «да» из 211 (351 из 1266, 27,7 %). 16 строк hybrid GigaChat с отсутствующим номером статьи по решению Марка считаются галлюцинацией (`УПУЩЕНИЕ`).
- Протокол разметки и нормализованные метки пока не перенесены в репозиторий; до этого числа в статье не воспроизводятся из `results/*.xlsx`.
- В `zero_shot_deepseek_v2_final.xlsx` пометки «Источник: DeepSeek (majority)» / «Gemini (majority/agreement)» были удалены автором 12.11.2026; файл перезаписан, метки теперь читаются как обычная разметка по тегам.
- Аннотация и обзор литературы в `.tmp/другие-готовые-части-статьи/` описывают 75–100 вопросов, четыре архитектуры (включая GraphRAG/Agentic), RAGAS и юридического эксперта. Это расходится с фактической матрицей; части нужно согласовать с авторами, не переписывая их без запроса.
