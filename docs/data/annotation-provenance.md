# Происхождение и проверка финальной разметки (v2)

**Статус:** финальная разметка для статьи. Собрана 14.11.2026, проверена 16.11.2026.
**Источник истины:** `results/annotations/annotations_v2.xlsx` — 1266 строк, 6 прогонов × 211.
**Коротко:** 341 галлюцинация из 1266 (26,9 %); 29 отказов, из них 11 при эталонной статье в контексте и 18 без неё.

## Что лежит в репозитории

- `results/annotations/annotations_v2.xlsx` — полная таблица: ответы моделей, итоговая метка, тег, комментарий разметчика, найденные статьи и два признака (`Эталонная статья в контексте`, `Отказ`).
- `results/annotations/_итоги.tsv` — машиночитаемые агрегаты по шести прогонам.
- `results/annotations/results_fig1.png` — рисунок 1 для раздела «Результаты».
- `results/annotations/README.md` — краткая памятка по папке.
- `scripts/verify_annotations.py` — проверка целостности и соответствия `results/**/*_v2.xlsx`.
- `scripts/compute_annotation_stats.py` — пересчёт чисел и `_итоги.tsv`.
- `scripts/make_results_fig.py` — сборка рисунка 1.

## Источники

## Схема таблицы

`Прогон, №, Глава, Вопрос, Ответ, Статья ТК РФ, Ссылка на источник, Ответ модели, Была галлюцинация (да/нет), Комментарий, Тип ошибки, Найденные статьи, Эталонная статья в контексте, Отказ`.

- `Ответ модели` — ответ, сохранённый в `results/**/*_v2.xlsx`; скрипт проверки сверяет его построчно.
- `Была галлюцинация (да/нет)` — итоговая метка после применения правила отказов.
- `Тип ошибки` — один из четырёх тегов; заполнен тогда и только тогда, когда метка «да».
- `Эталонная статья в контексте` — `да` / `нет` / `н/п`; проверка на уровне статьи, а не отдельного чанка. `н/п` — для zero-shot, где ретривала нет.
- `Отказ` — `да` / `нет`; модель не дала ответа по существу, а лишь констатировала отсутствие нормы или ответа во фрагментах.

## Правила разметки

- Четыре тега: `ВЫДУМАННЫЙ ФАКТ`, `НЕВЕРНАЯ СТАТЬЯ`, `УПУЩЕНИЕ`, `ВЫДУМАННАЯ СТАТЬЯ`. При нескольких нарушениях ставится один тег по приоритету.
- Любой непустой тег означает галлюцинацию; отсутствие тега — галлюцинации нет.
- Отказ при эталонной статье в контексте → `ВЫДУМАННЫЙ ФАКТ`, метка «да»: модель утверждает, что нормы в контексте нет, хотя статья была передана.
- Отказ без эталонной статьи в контексте → метка «нет», тег пустой: это промах ретривала, а не галлюцинация; такие строки анализируются отдельно.
- Не-отказы сохраняют исходную разметку.
- Каждый прогон размечал один участник; согласованность разметчиков не оценивалась, повторная разметка не проводилась. Никто из разметчиков не являлся юристом; единственный юрист проекта в разметке не участвовал.
- LLM-судья давал предварительную метку; итоговая таблица — результат автоматической оценки и ручной проверки, а не независимой человеческой разметки в строгом смысле.

## Проверка и воспроизводимость

```powershell
python scripts/verify_annotations.py
python scripts/compute_annotation_stats.py
python scripts/make_results_fig.py
```

`verify_annotations.py` проверяет 1266 строк, 6 прогонов × 211, ответы и `Найденные статьи` против `results/**/*_v2.xlsx`, флаг контекста, соответствие «метка ⟺ тег» и правило отказов; при расхождении возвращает код 1. `compute_annotation_stats.py` пересчитывает доли, ДИ Уилсона, точный МакНемар, теги, отказы, ловушки и перезаписывает `_итоги.tsv`. `make_results_fig.py` пересобирает рисунок 1.

Ожидаемый итог: 1266 строк, 341 галлюцинация (26,9 %), 29 отказов (11 со статьёй в контексте, 18 без), теги 135/123/80/3.

## Ограничения

- `Эталонная статья в контексте` — проверка на уровне статьи, а не отдельного чанка. Для hybrid v2 нет retrieval-jsonl, поэтому покрытие чанка не проверялось.
- Отказ определялся эвристикой по тексту с ручным просмотром кандидатов; это не независимая экспертная разметка.
- В `results/hybrid_rag/deepseek/hybrid_rag_deepseek_v2.xlsx` у ID 112 не заполнена колонка `Найденные статьи_DeepSeek_HybridRAG`; в размеченном источнике retrieval для этой строки есть (`tk-92, tk-94, tk-267, tk-91, tk-96`). Флаг контекста для ID 112 взят из размеченного источника; скрипт проверки выводит об этом предупреждение.
- Комментарии разметчиков сохранены как есть; в части строк они описывают исходную метку и могут не отражать пересчёт по правилу отказов. Для итоговых чисел используется `Была галлюцинация` и `Тип ошибки`, а не текст комментария.
- Согласованность разметчиков не оценивалась, повторная разметка не проводилась, юрист к разметке не привлекался.

## Политика обновления

`results/annotations/annotations_v2.xlsx` — источник истины для финальных чисел статьи. При любом изменении размеченных таблиц в той же задаче обновляйте:

- SHA-256 в этом файле;
- `results/annotations/_итоги.tsv` (перезапуском `scripts/compute_annotation_stats.py`);
- ключевые числа в `results/annotations/README.md`;
- рисунок `results/annotations/results_fig1.png`;
- числа в разделах Methods/Results статьи.

Перед фиксацией запускайте `python scripts/verify_annotations.py` и `python scripts/compute_annotation_stats.py`. Расхождение между таблицей, агрегатами, рисунком и текстом статьи недопустимо. Это же правило зафиксировано в `AGENTS.md`.
